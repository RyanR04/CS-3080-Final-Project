# CS-3080-Final-Project

## Overview

This weather app is a python desktop application built with tkinter and using data from OpenWeather.api. It will display daily weather and a 5-day forecast. While letting users save certain cities to get quick aceess.

### Features
- Current Weather
- 5-day forecast
- Save favorite cities
- Remove favorite cities
- Temp Conversion (Celsius/Fahrenheit)
- Sunrise and sunset times
- Error Handlling 

### Major Libraires and Tools Used 
- Python
- Tkinter
- Requests
- Pillow 
- ThreadPoolExecutor
- OpenWeather API
- Datetime

### Instalation Requirements
1. Must clone this repository. 
2. Install all required libraries including pillow.
3. Make sure to create own API_File and put key on first line.
4.Run Application

### How to Use
1. Enter a city name and click search
2. View current weather and convert by using convert button.
3. Save cities using save and remove when wanted
4. On homepage click saved cities for quick access
